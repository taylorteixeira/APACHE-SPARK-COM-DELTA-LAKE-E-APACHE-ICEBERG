# O que é Iceberg

Apache Iceberg é uma especificação de tabela aberta para data lakes analíticos. Ele foi projetado para resolver os desafios de gerenciamento de dados em data lakes, fornecendo recursos avançados de gerenciamento de tabelas.

## Principais Recursos

- **Schema Evolution**: Evolução segura do schema
- **Partition Evolution**: Mudança de partições sem reescrita
- **Time Travel**: Acesso a snapshots históricos
- **Transações ACID**: Garantia de consistência
- **Otimização de Consultas**: Pruning de partições e arquivos

## Benefícios

1. **Performance**: Otimizações avançadas para consultas
2. **Escalabilidade**: Suporte a grandes volumes de dados
3. **Confiabilidade**: Garantias de consistência
4. **Flexibilidade**: Suporte a múltiplos formatos
5. **Interoperabilidade**: Compatibilidade com várias engines

## Casos de Uso

- Data lakes analíticos
- Data warehousing moderno
- Análise de dados em tempo real
- Machine Learning
- Business Intelligence

## Diferenças em Relação ao Delta Lake

- Foco em otimização de consultas
- Suporte nativo a múltiplas engines
- Abordagem mais modular
- Maior flexibilidade em partições
- Melhor suporte a metadados
